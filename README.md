# alumni-map
This deposit is to produce an interactive map of the info of alumni from Earth and Environmental Sciences Department in CUHK

Integrated geospatial visualization and user-friendly exploration of alumni information.

I stored alumni metadata such as names, current institution/company, current location coordinates, a one-sentence biographies, and the group they belonged to in a JSON dataset. 

I used JavaScript, the Leaflet mapping library, and OpenStreetMap tiles for geospatial presentation. 

The website dynamically loads the alumni dataset with map markers using latitude and longitude coordinates, and generated pop-up windows showing the alumnus profile when users clicked a marker.
