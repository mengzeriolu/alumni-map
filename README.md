# alumni-map
This deposit is to produce an interactive map of the info of alumni from Earth and Environmental Sciences Department in CUHK
https://mengzeriolu.github.io/alumni-map/

I stored alumni metadata such as names, current institution/company, current location coordinates, one-sentence biographies, and the group they belonged to in a JSON dataset. 

I used JavaScript, the Leaflet mapping library, and OpenStreetMap tiles for geospatial presentation. 

The website loads the alumni dataset with map markers attributed with latitude and longitude coordinates, and generated pop-up windows showing the alumnus profile when users clicked a marker. 

To edit or add data, please go to alumni.json, copy an existing entry and update name, bio, coordinates... accordingly. Upload a photo to the folder "images" with the same name as indicated in the json entry.
